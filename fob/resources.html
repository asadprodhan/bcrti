Access Model

This GitHub repository serves as the student-facing landing page for the Foundations of Bioinformatics micro-credential. Restricted participant resources can be managed separately through restricted Google Drive, private repositories or controlled-access forms.

Public-facing information is available through this website, while teaching files, workshop datasets, quizzes and feedback activities can be shared only with enrolled participants.
